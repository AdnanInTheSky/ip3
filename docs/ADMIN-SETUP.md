## Environment variable map

| Variable | Scope | Purpose |
|---|---|---|
| `SITE_URL` | Vercel build; Production | `https://ip3-bd.org` canonical base and sitemap host |
| `PUBLIC_TURNSTILE_SITE_KEY` | Vercel build; Production and only approved previews | Public widget key rendered into HTML |
| `CONTACT_API_ENABLED` | Vercel build; Production, after all release gates | Set to `1` to enable browser POSTs to `/api/contact`; unset means the form uses only its `mailto:` fallback |
| `TURNSTILE_SECRET` | Vercel runtime; server-only | Cloudflare Siteverify credential |
| `RESEND_API_KEY` | Vercel runtime; server-only | Resend credential |
| `CONTACT_TO` | Vercel runtime; server-only | Confirmed recipient mailbox |
| `CONTACT_FROM` | Vercel runtime; server-only | Sender address on the Resend-verified domain |
| `VERCEL_AUTOMATION_BYPASS_SECRET` | GitHub Actions secret; only if deployment protection requires it | Authenticated GET access for smoke and uptime workflows |
| `UPTIME_URL` | GitHub Actions repository variable; set after DNS points at Vercel | Production domain or approved `ip3-bd-org.vercel.app` target for the scheduled uptime check |
| `ENABLE_ANALYTICS` | Vercel build; Production, after privacy review | Enables the analytics snippets only when set to `1` |
| `CI_FAILURE_WEBHOOK_URL` | GitHub Actions secret; optional | Optional owner-approved failure webhook; no-op when absent |

The endpoint's exact recipient and sender names are `CONTACT_TO` and `CONTACT_FROM`; `TURNSTILE_SECRET` is required server-side whenever contact delivery is used. Generated pages omit `data-contact-api` unless `CONTACT_API_ENABLED=1`; while unset, the form validates locally and opens the prefilled `mailto:` without making a network request. Delivery retains that fallback on API failure. Require Turnstile before enabling delivery. No datastore is used. No datastore is used. The live form remains disabled until the owner has confirmed the mailbox, legal wording, US processing, Resend sender verification, Turnstile keys, and an abuse-control choice.
