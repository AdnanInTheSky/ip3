# Editorial and graph review

Date: 22 October 2026. Scope: current hub, six native model pages and the homepage’s analytical/hero entry experience. Assessment perspectives: economists/appraisal specialists, academic methods reviewers, evaluators, policy analysts and institutional funders. This is an assessment for their review, not a claim that any institution or academic has accepted the work.

## Important fresh findings

1. **Input metadata defect (new IP3-17, P0).** `src/explore/index.js:model` read `min/max/step` as Linkedom IDL properties. Those properties were undefined in the server renderer, became `NaN` in the no-JS table and `null` in JSON. Previous browser proofs did not assert this contract, so their “max” vectors could fall back to the range control’s default behavior. The fix reads actual attributes, validates finite bounds/defaults and shares human-readable labels with the browser. New assertions match every metadata value with the real DOM controls before running both engines’ full reset/series checks. Prior arithmetic evidence is retained; its boundary-coverage limitation is explicitly corrected.
2. **Residual unapproved claims (IP3-02 reopened, then remediated).** Enterprise’s static “400 firms / 120 interviews / 8 groups / Sweden–CPD” panel and one case’s method strings survived the earlier reference-field sanitization. They are replaced by a qualitative three-stage research-method panel, retaining its layout. Delivery’s “documented professional engagement” boundary is replaced by a hypothetical-application boundary. Neither the source count nor an institutional credit is asserted without approval. Immutable original prototypes are unchanged.
3. **Impact line mismatch (new IP3-20, P2).** The plotted constructed counterfactual is dotted, but an old footnote said dashed. It now says “The dotted line is a constructed counterfactual.” The comparison line remains dashed. This is interpretation correction, not a new causal model.
4. **Homepage motion control (new IP3-19, P1).** Hover-only carousel pausing was insufficient for a keyboard reader. An explicit pause/resume control, keyboard focus hold and reduced-motion/visibility handling are added using existing control styling. All configured visible homepage slides remain; the CMS has six records with five currently visible. No hidden CMS record is unhidden to satisfy a test.

Before/after captures for each substantive visible correction are in `FINAL_QA_EVIDENCE`: `input-bounds-nojs-*`, `enterprise-claims-*`, `delivery-claim-*`, `impact-line-note-*` and `home-*`. Browser screenshots are proof, never replacements for the interactive graphics.

## Visualization and precision audit

- **Axes and units:** chart descriptions and complete readable tables specify indices, USD millions, units/month, pp versus percentage levels, hours/case and packages/week. Defaults/bounds exports must remain numerical and match the controls. A positive synthetic scenario is not evidence of achieved performance.
- **Signed values:** Finance retains negative initial investment and all later flows; Enterprise retains negative contribution/profit; Governance retains negative released hours; Impact retains and flags infeasible constructed values. No clipping is used to hide an adverse outcome.
- **Thresholds:** Trade has reference 100; Finance’s arithmetic NPV threshold is zero; Enterprise uses the exact continuous crossing with upward whole-unit KPI rounding; Impact contrast zero means equal changes, not causal proof; Governance zero means no workload difference; Delivery target is week 24, not an estimated probability.
- **Colour alternatives:** solid/dashed/dotted line differences and hatched rework supplement colour. Direct values, descriptions and full tables support interpretation without relying on a graph alone. Human screen-reader usability remains unaccepted.
- **Series reconciliation:** actual browser JSON/CSV, readable table cells and SVG coordinates are compared using independently expressed expected values. Current browser contracts reject missing/nonfinite metadata before testing endpoints. Readable values may round to six decimals; JSON/CSV retain numeric precision. More digits do not imply empirical precision.
- **Conceptual diagrams:** homepage concept-map geometry does not move with a sensitivity slider. The numerical output and assumptions are separate. The original conceptual diagrams and animations are preserved.
- **Motion:** model motion/tour controls, reduced motion and native page scrolling are retained; new homepage pause/focus handling addresses reader control. No decorative animation is added to imply a measured relationship.

## Editorial standards and remaining limits

Use precise verbs such as “illustrates”, “assumes”, “compares” and “tests sensitivity”. Keep conditional decision rules and next evidence visible. Do not upgrade these pages to “validated”, “proven impact”, “verified client outcomes” or decision forecasts without evidence. References explain methods and context; they do not calibrate synthetic coefficients or imply endorsement.

The six scientific dossiers provide individual equations, assumptions, misuse risks, calibration requirements, uncertainty needs and human acceptance tasks. Existing Engagements are linked separately; this audit does not retroactively approve the publication rights or empirical claims of every existing site record. Source citations are verified primary/institutional links, with author–year metadata where established. Textbook/reference prose and artwork have not been copied into the site.
