# SEO audit — IP3 Consulting (25 October 2026)

**Scope:** full-site audit of the static build (33 pages, 32 in the sitemap) and the live hosts `ip3-bd.org` and `ip3-bd-org.vercel.app`.

**Method:** the `marketing:seo-audit` framework (keywords, on-page, content gaps, technical, competitors) combined with the checklists from [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo) v2.5 (commit `6be93f4`; 20k stars, the most-starred dedicated SEO project for Claude Code): `seo-page`, `seo-technical`, `seo-schema` and `seo-geo`. Only the checklists were used; none of claude-seo's scripts were run. Every built page was scanned with a local script that checks title and description length, H1 count, heading order, image alt and dimensions, word count, robots, OG/Twitter tags and JSON-LD validity.

**Data limits:** no SEO tool (Ahrefs, Semrush, Search Console) is connected. Search volume, difficulty, rankings and backlinks below are **estimates from web search and site inspection, not measurements**. Connect Ahrefs (`/mcp`) or Search Console to replace them with real data.

## Executive summary

The technical base is strong. The site is generated as static HTML, so every page's content is in the raw HTML. Every page has one H1, a self-referencing canonical, a unique title and description, alt text on every image and valid JSON-LD. The sitemap and robots.txt are correct, and security headers and HSTS are set.

There are three priorities:

1. **Domain cutover (critical, owner action).** `ip3-bd.org` still serves the old WordPress site on Hostinger. The new site's canonicals point to `https://ip3-bd.org/...` paths that return **404** there (checked: `/about`, `/capabilities`, `/why-ip3`, `/sectors/climate-energy-resilience`). Until the domain points at the new build, Google has nothing valid to index.
2. **Brand disambiguation.** A search for "IP3" returns the US *Institute for Public-Private Partnerships* (a Tetra Tech company). IP3 Consulting needs "Bangladesh/Dhaka" in key titles, a consistent Organization entity and third-party profiles (`sameAs`) to win its own brand results.
3. **Content depth.** The site has 4 Insights articles and 32 URLs. LightCastle Partners has about 861 posts in its post sitemap, and Innovision has 324 sitemap URLs. Service and topic pages are what rank for "consulting firm Bangladesh" queries.

**Overall: strong technical foundation; launch is blocked by the domain cutover; content needs work.**

## Applied in this change (quick wins)

| Change | Where | Why |
|---|---|---|
| Meta descriptions are trimmed to ≤160 characters at a sentence boundary (or at a word, with "…") | `src/layout.js` `metaDesc()` | 12 pages had descriptions of 167–228 characters, which search results cut off mid-sentence |
| Sector descriptions name as many service areas as fit in 160 characters | `src/sec/index.js` | All 8 sector descriptions were 167–213 characters |
| Home title → "IP3 Consulting \| Policy & Development Advisory in Bangladesh" (60 chars); home description shortened to 151 chars from the same claims | `content/pages.json` | Was 71 + 213 chars, with no location term, so it competed with the US "IP3" |
| Organization gets `@id`, `founder` and `knowsAbout` (the 8 sector names) | `src/layout.js` | Builds one entity graph; founder and sector expertise are E-E-A-T signals |
| WebSite gets `@id`; `name` = "IP3 Consulting", `alternateName` = legal name, `publisher` → Organization | `src/pages-home.js` | Google takes the site name shown in results from WebSite `name` |
| Breadcrumb JSON-LD uses the page title for the last crumb, instead of the URL slug | `src/layout.js` | Was "Ai emerging technology public systems", "Bangladeshs esg transition…" |
| Articles: `og:type=article`, cover image as `og:image`, and Article `description`, `image`, `articleSection`, `author`/`publisher` → Organization | `src/pages-articles.js` | Article markup lacked publisher, author and image |
| Sector pages: `Service` JSON-LD (name, description, service areas, provider) | `src/sec/index.js` | No service markup existed |
| People page: `ItemList` of `Person` (name, job title, profile anchor) | `src/pages-inner.js` | Expert visibility (E-E-A-T); no person markup existed |

Checked after the change: `npm test` 128/128 pass, `npm run check` OK, `npm run links` OK, 81 JSON-LD blocks parse and each has `@context` and `@type`.

**Approved (25 October 2026, Rahat):** the new home title and description wording, and "Policy & Development Advisory in Bangladesh" as the positioning. Merged in PR #42 and live.
